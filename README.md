# Audio Enhancement with Generative Adversarial Networks

A conditional Generative Adverserial Network (cGAN) augments spectrograms from low-end equipment with audio features found in more expensie microphones. 

## Usage

### Creating the Dataset

Ensure raw data is formatted as

```python
raw_data/
└── year/
    ├── microphone_1/
    │   ├── location1/
    │   │   └──location_YYYYMMDD_HHMMSS.wav
    │   └── location2/
    │   │   └──location_YYYYMMDD_HHMMSS.wav
    └── microphone2/
        ├── location1/
        └── location2/
```

Running the main script creates the dataset by pairing field recorings, trains the model and runs the evaluation pipeline.

Hyperparameters are modified from the configuration file.

`create_dataset` generates lists of recordings whose time and dates exactly match. Each microphone folder using filenames which must be formatted as `LOCATION_YYYYMMDD_HHMMSS.wav`  The dataset creation pipeline supports manual summary files however any mistakes with filenames or formatting propagates through and can cause unexpected behaviour.

File names from the high-quality microphone must include a delimiter, for example input from the SMMicro (low quality) has the filename `PLI1_20231104_125433.wav`. The high quality microphone, SM4, has the same name but with the delimiter `-4` included: `PLI1-4_20231104_125433.wav`.

Full summary files for each location should contain at least the latitude, longitude, date and time of each recording, and be kept in a folder `full_summaries` just under the parent directory. This allows geolocating the recordings during evaluation and allows extensibility - if more metadata is added, more analysis can be done. 

The pipeline also outputs all matched recordings between the microphones, a JSON file visualising the directory structure and a training/validation/test set for the cGAN. Metadata for audio reconstruction such as magnitude, phase, recording length and more is kept for test set recordings.

Each image in the dataset is a composition of input and target images, with the training sample on the left and the target on the right.

### Training the Model

Images generated by the model during training and validation are saved in the dataset/train_runs folder. Generated, input and target images are saved as a trio, with a sample per epoch to stay memory efficient. The metrics Peak Signal to Noise Ratio (PSNR) and Structural Similarity Index Measure (SSIM) are used to analyse the quality of model output during training.

Images were not compressed and have been padded to fit into U-Nets required dimensions, in the series $2^n$. Images have padding removed and are normalised before being saved to disk.

Data generated from the test set is automatically saved. 

### Evaluating the Model

Evaluation transforms a generated spectrogram into audio, using the target spectrograms magnitude and phase. Multiple acoustic indices, measures that enable quantifiable comparisons of the generated and target images, are employed.

Generated and target audio are then run through BirdNet so eco-acoustic quality is compared.
